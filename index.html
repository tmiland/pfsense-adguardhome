pfSense-pkg-adguardhome

pkg(8) repository for pfSense-pkg-adguardhome — an adopt-first AdGuard Home manager package for pfSense: auto-install, service integration, and native Status/Settings UI. It never touches a working install and never writes AdGuardHome.yaml.

Install (CLI on the pfSense box)

mkdir -p /usr/local/etc/pkg/repos
cat > /usr/local/etc/pkg/repos/pfsense-adguardhome.conf <<'EOF'
pfsense-adguardhome: {
    url: "https://tmiland.github.io/pfsense-adguardhome/repo",
    mirror_type: "none",
    signature_type: "none",
    enabled: yes
}
EOF
pkg update
pkg install -y -r pfsense-adguardhome pfSense-pkg-adguardhome

Then open Services → AdGuard Home in the pfSense web UI. On a fresh install, finish setup once via AdGuard Home's own wizard at http://<firewall>:3000; an existing install is adopted untouched.
